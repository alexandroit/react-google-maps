# Changelog

All notable changes to `@stackline/react-google-maps` are documented here.

## [Unreleased]

- Moved exact-version dependency records to `package.fixture.json`, repaired
  their validators, and added an offline catalog contract to keep historical
  metadata out of active dependency alerts.
- Forced tsup's nested esbuild onto the patched release line.
- Added a package-specific security policy and confidential reporting path.
- Added reproducible CI packaging and a manual npm provenance release workflow.
- Included release and security documentation in the published package.

## [19.0.0] - 2026-04-05

- Published the React 19 compatibility line.
- Added versioned documentation for React 17, React 18, and React 19.
- Added declarative map, marker, shape, layer, directions, and geocoding wrappers.

## [18.0.0] - 2026-04-05

- Published the React 18 compatibility line.

## [17.0.0] - 2026-04-05

- Published the initial React 17 wrapper line.
